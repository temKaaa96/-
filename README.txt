Кидай сюда файлы — они автоматически появятся в галерее «🎨 Оформление → Фон».
Поддерживаются:
  • видео:    .mp4 .webm
  • гифки:    .gif
  • картинки: .jpg .jpeg .png .webp

Имя файла станет подписью в галерее (например  space.mp4  → «space»).
Никакой код менять не нужно — просто залей файлы в эту папку и передеплой.
